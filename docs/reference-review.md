## Límites del APK

Un APK es un paquete Android compilado, no el proyecto fuente. Se pueden inspeccionar algunos metadatos, recursos, componentes y partes del bytecode; eso no recupera de forma fiable el código fuente original, entorno de compilación, lógica de servidor, datos de producción, claves privadas ni todos los flujos. La ofuscación, bibliotecas nativas, configuración remota y controles de servidor limitan más las conclusiones.

La revisión debe ser autorizada y funcional. No extraer ni reutilizar secretos, credenciales, tokens, claves, código propietario ni identidad visual protegida.
